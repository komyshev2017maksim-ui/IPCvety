# Антидетект: браузерные профили для сетки Instagram

У каждого бренда своя карточка и свой браузер: отдельные cookies и сессии, свой прокси, часовой пояс по IP прокси и свой отпечаток устройства. Профили открываются вручную из панели. Регистрацию, вход и все действия на сайтах вы делаете сами, софт на страницах ничего не нажимает.

Работает с обычным установленным Google Chrome или Microsoft Edge. Написан на Python, зависимость одна: `websockets`.

## Установка на Windows

Всё ставится на диск D.

```bat
D:
cd "D:\Маркетинг\Claude"
git clone https://github.com/komyshev2017maksim-ui/IPCvety.git antidetect
cd antidetect

set PIP_CACHE_DIR=D:\Маркетинг\Claude\.pip-cache
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Нужен Chrome или Edge (Edge в Windows уже есть). Данные профилей лежат в папке `data` рядом с кодом; другую папку задаёт переменная `ANTIDETECT_HOME`:

```bat
setx ANTIDETECT_HOME "D:\Маркетинг\Claude\antidetect-data"
```

## Быстрый старт

1. Запустите `start.bat`. Откроется панель `http://127.0.0.1:8765`.
2. Нажмите «Создать 33 карточки брендов». Появятся IG-01 … IG-33 с названиями, сайтами и группами.
3. «Прокси списком»: вставьте прокси по одному на строку, они разойдутся по карточкам без прокси.
4. «Проверить все IP» покажет страну, город, отклик и пояс каждого прокси.
5. «Открыть» запускает браузер профиля. Закрыть можно крестиком окна или кнопкой в панели.

## Что умеет панель

- **Карточка профиля:** бренд, сайт, группа, статус (Не начат, Готовлю, Зарегистрирован, Прогрев, Работает, Проблема, Бан), метки, логин Instagram, почта, номер, дата окончания аренды номера, заметки, семь шагов запуска.
- **Разделы слева:** все, открытые, требуют внимания (ошибка запуска, статус «Проблема» или «Бан», аренда номера кончается через 5 дней и раньше, IP не в США), без прокси, корзина, группы по нишам.
- **Поиск, фильтр по статусу, сортировка** по клику на заголовок. Клавиша `/` ставит курсор в поиск.
- **Статус в один клик** прямо в строке.
- **Массовые действия:** отметьте строки, внизу появится панель: открыть, закрыть, проверить IP, статус, группа, прокси списком, в корзину.
- **Прокси списком:** форматы `host:port`, `host:port:user:pass`, `user:pass@host:port`, `http://…`, `socks5://user:pass@host:port`. SOCKS5 с паролем поддерживается.
- **Проверка прокси:** IP выхода, флаг страны, город, провайдер, отклик. Точка зелёная, жёлтая (отклик дольше 2,5 с) или красная (не та страна).
- **Повторы:** жёлтая плашка, если у двух профилей совпал прокси, IP выхода, логин, почта или номер.
- **Cookies:** экспорт в JSON и импорт из JSON или Netscape у закрытого профиля (меню «⋯»).
- **Копия профиля:** те же бренд, группа и метки, новый отпечаток, пустой браузер. Прокси, логин, почта и номер не копируются.
- **Корзина** с восстановлением. «Удалить навсегда» стирает и данные браузера.
- **Журнал** в карточке: запуски, проверки IP, смены статуса.
- **Страницы проверки:** из меню «⋯» профиль открывается сразу на Pixelscan, CreepJS, BrowserLeaks, BrowserScan, IPhey или Whoer.
- **Импорт** `instagram-profiles.json` из старой панели учёта. Повторный импорт дубликатов не создаёт.
- Тёмная и светлая тема.

Всё то же есть в командной строке: `python -m antidetect -h` (команды `seed`, `import`, `add`, `set`, `list`, `show`, `check`, `open`, `stop`, `cookies`, `regen`, `rm`, `ui`).

## Что видит сайт

Chrome запускается как обычная программа, без флагов автоматизации: `navigator.webdriver` равен `false`, жёлтой полосы «неподдерживаемый флаг» нет, окно свободно меняет размер.

| Параметр | Откуда берётся | На каком уровне |
|---|---|---|
| Cookies, localStorage, кэш | своя папка на профиль | отдельный каталог данных Chrome |
| IP | прокси профиля | весь трафик браузера; DNS резолвит прокси |
| Часовой пояс | по IP прокси, иначе по городу и штату | движок |
| Язык, формат дат | `en-US` | настройки браузера и движок |
| Геолокация | координаты города по IP | движок; отдаётся, только если вы разрешите сайту |
| WebRTC | только через прокси | настройка Chrome |
| Размер экрана | из отпечатка | движок (сходится с CSS media queries) |
| Число ядер | из отпечатка | движок |
| Память устройства | из отпечатка | скрипт |
| Видеокарта (WebGL) | из отпечатка; WebGPU отвечает «не поддерживается» | скрипт |
| Canvas | шум в младшем бите части пикселей | скрипт |
| AudioContext | микросдвиг сэмплов | скрипт |
| Система, версия Chrome, шрифты | настоящие | не подменяются |

Скрипт подмены ставится до скриптов сайта в каждой вкладке, фрейме и воркере, поэтому страница и воркер видят одно и то же устройство. Отпечаток создаётся один раз и хранится в карточке; шум canvas и аудио детерминированный. Сменить отпечаток можно в карточке, но для сайта это будет новое устройство.

## Защита от ошибок при запуске

Профиль не откроется, если прокси не задан, не отвечает, не принимает логин и пароль, выходит не в США или если неизвестен часовой пояс. Предупреждения без остановки: IP выхода сменился, тот же IP уже был у другого профиля, пояс из карточки не совпал с поясом IP (берётся пояс IP).

Fraud score адреса софт не проверяет, это делается на стороннем сервисе.

## Где лежат данные

```
data/
  profiles.json        карточки, отпечатки, прокси с логином и паролем
  settings.json        необязательные настройки
  browser-data/ig-01/  cookies и сессии профиля, журнал
```

Пароли прокси хранятся в `profiles.json` открытым текстом. Папка `data` исключена из git. Пароли от Instagram софт не хранит. Панель слушает только `127.0.0.1` и пароли прокси в браузер не отдаёт.

Резервная копия: закройте все профили и скопируйте папку `data`.

## Настройки

Файл `data/settings.json`, все ключи необязательные:

```json
{
  "browser": "auto",
  "expected_country": "US",
  "ip_services": ["https://ipinfo.io/json", "https://ipapi.co/json/"],
  "start_url": "https://www.instagram.com/",
  "ui_port": 8765,
  "spoof": {"hardware": true, "webgl": true, "canvas": true, "audio": true}
}
```

`browser`: `auto` (Chrome, затем Edge, затем Chromium), `chrome`, `msedge`, `chromium` или полный путь к exe. Блок `spoof` выключает отдельные подмены для всех профилей.

## Ограничения

- **Проверено только в Linux** на Chromium 153, с окном и без. На Windows с настоящим Chrome и на живом Instagram код не запускался. Первый профиль проверьте на страницах из меню «⋯».
- Это обычный Chrome с подменами поверх, а не пересобранный движок. Подмены скриптом (видеокарта, память, canvas, аудио) строгий тест вроде CreepJS может заметить: шум canvas виден на однотонной заливке, обёрнутые функции находятся глубокой проверкой. Если тест ругается, выключите лишнее в `spoof`.
- Шрифты и система настоящие, одинаковые у всех профилей.
- Пока профиль открыт, на `127.0.0.1` слушает порт отладки Chrome. Сайты до него не достают, но другая программа на вашем компьютере может.
- Главное, что связывает аккаунты, это общий IP, cookies, номер или почта и одинаковое поведение. Отпечаток идёт после них. Правила Instagram запрещают обход их защиты, блокировки возможны при любом отпечатке.

## Тесты

```bat
pip install pytest
python -m pytest
```

Тесты запускают настоящий браузер, открывают локальную страницу и проверяют, что страница и воркеры видят значения из отпечатка, что `navigator.webdriver` выключен, что у двух профилей canvas разный, а у одного одинаковый между запусками, что прокси с паролем (HTTP и SOCKS5) работают, а cookies не пересекаются между профилями.
