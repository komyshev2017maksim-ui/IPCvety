# Антидетект: браузерные профили для сетки Instagram

Каждый бренд получает свой браузерный профиль: отдельные cookies и сессии, свой прокси, часовой пояс по IP прокси и свой отпечаток устройства. Профили открываются вручную из панели или из командной строки. Регистрацию и вход вы делаете сами, софт ничего на сайтах не нажимает.

Сделано на Python и Playwright. Работает с установленным Google Chrome, а если его нет, с Chromium из Playwright.

## Установка на Windows

Всё ставится на диск D, на C ничего не пишется, кроме самого Python и Chrome, если они уже там.

```bat
D:
cd "D:\Маркетинг\Claude"
git clone https://github.com/komyshev2017maksim-ui/IPCvety.git antidetect
cd antidetect

set PIP_CACHE_DIR=D:\Маркетинг\Claude\.pip-cache
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Если Google Chrome не установлен, скачайте Chromium (ляжет в папку данных, около 400 МБ):

```bat
python -m antidetect install-browser
```

Данные профилей лежат в папке `data` рядом с кодом. Другую папку задаёт переменная `ANTIDETECT_HOME`:

```bat
setx ANTIDETECT_HOME "D:\Маркетинг\Claude\antidetect-data"
```

## Быстрый старт

1. В панели учёта нажмите экспорт и положите `instagram-profiles.json` в папку с кодом.
2. Запустите `start.bat` (или `python -m antidetect ui`). Откроется панель `http://127.0.0.1:8765`.
3. «Импорт JSON» создаст профили. Повторный импорт дубликатов не создаёт: профили ищутся по названию и номеру бренда, обновляются только изменившиеся поля, отпечаток и пароль прокси остаются прежними.
4. В «Изменить» впишите логин и пароль прокси (панель учёта их не экспортирует).
5. «Проверить IP» покажет, где выходит прокси. «Открыть» запустит браузер профиля.

То же из командной строки:

```bat
python -m antidetect import instagram-profiles.json
python -m antidetect set IG-01 --proxy 203.0.113.10:8000:login:password
python -m antidetect check --all
python -m antidetect open IG-01
python -m antidetect list
```

Профиль можно называть по имени (`IG-01`), номеру (`1`) или бренду. Остальные команды: `add`, `show`, `stop`, `regen`, `rm`. Справка: `python -m antidetect -h`.

Форматы прокси: `host:port`, `host:port:user:pass`, `user:pass@host:port`, `http://…`, `socks5://host:port`. SOCKS с логином и паролем Chromium не поддерживает, берите HTTP-порт того же прокси.

## Что видит сайт

| Параметр | Откуда берётся | Как подменяется |
|---|---|---|
| Cookies, localStorage, кэш | своя папка на профиль | отдельный каталог данных Chrome |
| IP | прокси профиля | настройка браузера |
| Часовой пояс | по IP прокси, иначе по городу и штату | на уровне движка, работает и в воркерах |
| Язык и формат дат | `en-US, en` | на уровне браузера, заголовок `Accept-Language` настоящий |
| Геолокация | координаты города по IP | на уровне движка, отдаётся только если вы разрешите сайту доступ |
| WebRTC | только через прокси | настройка Chrome, локальный IP не утекает |
| Размер экрана | из отпечатка | на уровне движка (сходится с CSS media queries) |
| `navigator.webdriver` | `false` | флаг запуска Chrome |
| Видеокарта (WebGL) | из отпечатка | скрипт в странице |
| Число ядер и память | из отпечатка | скрипт в странице |
| Canvas | шум в младшем бите части пикселей | скрипт в странице |
| AudioContext | микросдвиг сэмплов | скрипт в странице |
| Операционная система, версия Chrome, шрифты | настоящие | не подменяются |

Отпечаток создаётся один раз и хранится в профиле: при каждом входе устройство выглядит одинаково. Шум canvas и аудио детерминированный, от зерна профиля. Сменить отпечаток можно кнопкой «Новый отпечаток» или командой `regen`, но для сайта это будет новое устройство.

## Защита от ошибок при запуске

Перед открытием профиль проверяет прокси и не запустится, если:

- прокси не задан (иначе сайт увидел бы ваш настоящий IP);
- прокси не отвечает или не принимает логин и пароль;
- IP выхода не в США (страна задаётся в настройках);
- неизвестен часовой пояс (иначе браузер показал бы пояс вашего компьютера).

Предупреждения, которые запуск не останавливают: IP выхода сменился с прошлого раза, тот же IP уже был у другого профиля, пояс из панели учёта не совпал с поясом IP (берётся пояс IP). Команда `list` и панель показывают повторы прокси, IP выхода и логинов Instagram между профилями.

Fraud score адреса софт не проверяет, это по-прежнему делается вручную на стороннем сервисе.

## Где лежат данные

```
data/
  profiles.json        профили, отпечатки, прокси с логином и паролем
  settings.json        необязательные настройки
  browser-data/ig-01/  cookies и сессии профиля
```

Пароли прокси хранятся в `profiles.json` открытым текстом. Папка `data` и файл `instagram-profiles.json` исключены из git. Пароли от Instagram софт не хранит. Панель слушает только `127.0.0.1` и пароли прокси в браузер не отдаёт.

Резервная копия: закройте все профили и скопируйте папку `data` целиком.

## Настройки

Файл `data/settings.json`, все ключи необязательные:

```json
{
  "browser": "auto",
  "expected_country": "US",
  "languages": ["en-US", "en"],
  "ip_services": ["https://ipinfo.io/json", "https://ipapi.co/json/"],
  "start_url": "https://www.instagram.com/",
  "ui_port": 8765,
  "spoof": {"hardware": true, "webgl": true, "canvas": true, "audio": true}
}
```

`browser`: `auto` (Chrome, иначе Chromium), `chrome`, `msedge`, `chromium` или полный путь к exe. Блок `spoof` выключает отдельные подмены для всех профилей.

Размер окна сайта у профиля фиксированный и не растягивается вместе с окном браузера: так размер экрана и окна остаются согласованными. Поменять: `python -m antidetect set IG-01 --viewport 1280x640`.

## Ограничения

Это надстройка над обычным Chrome, а не пересобранный движок, как у коммерческих антидетектов. Отсюда слабые места:

- **Воркеры.** Скрипт подмены работает в страницах и фреймах, но не в Web Worker. Число ядер, видеокарта и canvas внутри воркера настоящие. Сайт, который сравнивает значения в странице и в воркере, расхождение заметит. Пояс, языки и WebRTC этим не страдают. Если хотите убрать риск расхождения, выключите `hardware` и `webgl` в `spoof`: значения станут настоящими и одинаковыми у всех профилей, что для 33 аккаунтов на частом железе не страшно.
- **WebGPU** отдаёт настоящую видеокарту.
- **Шум canvas** можно обнаружить, нарисовав однотонную заливку и прочитав её обратно.
- **Шрифты и ОС** настоящие, одинаковые у всех профилей.
- **Жёлтая полоса** «неподдерживаемый флаг» при запуске Chrome появляется из-за флага, который убирает `navigator.webdriver`. Её можно закрыть.
- На macOS язык интерфейса Chrome берётся из системы, флаг `--lang` там не действует.

Главное, что связывает аккаунты, это общий IP, общие cookies, один номер или почта и одинаковое поведение. Отпечаток стоит после них. Правила Instagram запрещают обход их систем защиты, аккаунты могут блокировать независимо от качества отпечатка.

## Тесты

```bat
pip install pytest
python -m pytest
```

Тесты запускают настоящий браузер без окна, открывают локальную страницу и проверяют, что она видит значения из отпечатка, что у двух профилей canvas разный, а у одного профиля одинаковый между запусками, и что запуск через прокси с паролем берёт пояс по IP.
